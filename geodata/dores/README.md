# geodata/dores/

Regional do Polo Dores (antigo "Polo Glória", renomeado — ver
`app/scripts/reconciliar_placeholders_interior.py`). O código operacional
430 — Glória segue existindo como uma localidade normal dentro deste polo,
sem relação com o nome da pasta.

Contém `dores.geojson`: limite oficial do município de Nossa Senhora das
Dores (código IBGE 2804607), usado para a localidade-sede do polo. Ver
geodata/README.md para o formato esperado e o processo de amarração via
`localidades.slug_geojson`.
