# Segurança — COI Sergipe Demo

**Este repositório é uma demonstração pública**, derivada do sistema interno COI Sergipe (Centro de Operação Integrado) da Energisa. **Não é o ambiente operacional real** e não contém nenhuma parte dele:

- Não há backend, banco de dados, autenticação de produção ou envio de e-mail — ver `README.md` para o detalhamento completo do que foi removido/substituído por simulação local.
- Nenhum dado operacional interno real (códigos de despacho, protocolos, escalas, contatos) foi incluído — os dados usados na demo são fictícios.
- O login desta demo (`demo`/`coi2026`) é só uma tela de exemplo, verificada localmente no navegador — não representa autenticação de produção nem controle de acesso real.

## O que não deve ser adicionado a este repositório

Por ser público, **nunca adicione** a este repositório:

- Links, URLs ou formulários internos da Energisa (Microsoft Forms, intranets, VPNs, etc.);
- Chamadas ou endereços de APIs privadas/corporativas reais;
- Credenciais, tokens, chaves de API, certificados ou arquivos `.env` reais;
- Dados corporativos reais (nomes de funcionários, telefones reais, códigos de despacho, protocolos operacionais, e-mails institucionais desnecessários).

Se qualquer um desses itens for encontrado neste repositório, remova-o e revise o histórico de commits antes de publicar/atualizar o repositório remoto.

## Reportar problemas

Abra uma issue neste repositório descrevendo o problema encontrado.

## Sistema operacional real (fora deste repositório)

O sistema em produção usado pela equipe do COI Sergipe é um projeto **separado**, com backend, banco de dados e controle de acesso reais — não faz parte deste repositório público e não deve ser confundido com ele.
